# adinball.com

Adrienne Ball's portfolio — static rebuild of the former Adobe Portfolio site, hosted on GitHub Pages.

- Plain HTML/CSS/JS, no build step needed to edit.
- Images live in `img/` (resized to max 2400px; originals kept in the Adobe export backup).
- Contact form posts to FormSubmit (adinball@gmail.com). The first submission sends a one-time activation email to that inbox.
- Custom domain: add a `CNAME` file containing `adinball.com` at cutover, then point DNS to GitHub Pages.
